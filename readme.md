# Alicahue [Web Api]
This is a web api developed using C# and .NET for serve content about student and
courses about the University Catholic of the North

    <img src="https://chilestudia.com/wp-content/uploads/2021/07/Logo_UCN-1.png" alt="drawing" width="150"/>
</p>



## Tecnologies 
The tecnologies used are the next
* C# 
* Mysql
* Entity Framework Core

## Running
For run the project you have execute the next commands

Clone the project

```bash
  git clone https://github.com/bxnjadev/alicahue-webapi
```

Run the project

```bash
  dotnet run
```
